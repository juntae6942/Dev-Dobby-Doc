# 뮤즈 (Musee) · 맞춤 공연 추천 및 관람 기록 플랫폼

KOPIS 공연 정보를 탐색하고, 관심 장르에 맞는 공연을 추천받으며, 관람 경험을 사진과 함께 티켓북에 남길 수 있는 서비스다. 백엔드 개발자로 공연 데이터 연동, 개인화 추천, 티켓북, 인증, 검색과 운영 도구를 개발했다. [백엔드 저장소](https://github.com/MUSEE-kopis/back), [프론트엔드 저장소](https://github.com/MUSEE-kopis/front)

## 주요 기여

### KOPIS 공연 데이터 연동

- KOPIS Open API에서 공연 데이터를 수집해 DB에 저장하고, 검색어 기반 공연 목록과 예매 순위 기반 인기 공연 조회를 구현했다. API 파라미터 변경에 대응하고 공연 상태 갱신, 장르와 예매 링크 제공을 추가했다. [PR #5](https://github.com/MUSEE-kopis/back/pull/5), [PR #30](https://github.com/MUSEE-kopis/back/pull/30), [PR #47](https://github.com/MUSEE-kopis/back/pull/47)
- 공연별 출연 배우 조회를 구현하고, 티켓북에 출연진을 목록으로 저장하도록 변경했다. 티켓북을 수정할 때 삭제한 배우 연결이 DB에 남는 문제를 정리했다. [PR #50](https://github.com/MUSEE-kopis/back/pull/50), [PR #51](https://github.com/MUSEE-kopis/back/pull/51)

### 티켓북과 개인화 추천

- 티켓북 저장·조회·수정과 S3 이미지 업로드·조회·삭제를 구현했다. 관람 기록 수에 따른 사용자 티어 산정도 추가했다. [PR #11](https://github.com/MUSEE-kopis/back/pull/11), [PR #13](https://github.com/MUSEE-kopis/back/pull/13), [PR #15](https://github.com/MUSEE-kopis/back/pull/15), [PR #20](https://github.com/MUSEE-kopis/back/pull/20)
- 회원의 관심 장르와 티켓북 기록을 공연 추천에 반영하도록 사용자별 장르 가중치를 관리했다. 가중치 데이터를 별도 테이블로 분리하고 초기화·갱신을 이벤트 처리로 전환했다. 이후 장르 기반 추천 로직을 보완하고 온보딩용 무작위 공연 조회를 추가했다. [PR #27](https://github.com/MUSEE-kopis/back/pull/27), [PR #36](https://github.com/MUSEE-kopis/back/pull/36), [PR #43](https://github.com/MUSEE-kopis/back/pull/43), [PR #48](https://github.com/MUSEE-kopis/back/pull/48)

### 검색어 자동완성

- 검색어 입력 빈도는 Redis Sorted Set에 기록하고, 접두사별 자동완성 후보는 메모리상의 Trie에 관리했다. 애플리케이션 시작 시 Redis에 저장된 검색어와 빈도로 Trie를 초기화하고, 검색어가 기록되면 빈도와 추천 후보를 갱신하도록 구현했다. [PR #58](https://github.com/MUSEE-kopis/back/pull/58), [자동완성 구현 커밋](https://github.com/MUSEE-kopis/back/commit/51d157c)

### 회원 인증과 운영 기능

- JWT 기반 회원가입·로그인, Kakao 로그인, 회원 탈퇴를 구현했다. 마이페이지의 회원 프로필과 장르 선호도 조회·수정 기능을 추가했다. [PR #3](https://github.com/MUSEE-kopis/back/pull/3), [PR #8](https://github.com/MUSEE-kopis/back/pull/8), [PR #17](https://github.com/MUSEE-kopis/back/pull/17), [PR #45](https://github.com/MUSEE-kopis/back/pull/45)
- 운영자가 로그인해 추천 공연을 등록·삭제할 수 있는 Thymeleaf 관리자 페이지를 구현했다. Actuator와 Micrometer로 메트릭을 노출하고 Prometheus·Grafana 모니터링을 구성했다. [PR #54](https://github.com/MUSEE-kopis/back/pull/54), [PR #57](https://github.com/MUSEE-kopis/back/pull/57), [PR #58](https://github.com/MUSEE-kopis/back/pull/58)
