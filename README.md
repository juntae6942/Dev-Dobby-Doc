# 🧦 개발자 도비문서 (Dev-Dobby-Doc)

> *"Master has given Dobby a JD... Dobby is building a resume to be free!"*

오직 **나만의 맞춤형 이력서 및 자기소개서 자동 생성**을 위해 구축한 개인 커리어 아카이브입니다.  
흩어져 있던 모든 프로젝트 경험, 트러블슈팅, 오픈소스 기여, 수상·학술 기록을 LLM(MCP)이 가장 잘 이해하고 추출할 수 있는 **정제된 Markdown(`.md`) 형태**로 모아둡니다.

## 목적
* 채용공고(JD)를 던져줬을 때, LLM이 이 저장소의 `.md` 파일들만 근거(Ground Truth)로 삼아 **할루시네이션 없이 사실 기반 이력서**를 조립하도록 함
* 매번 이력서를 쓸 때마다 기억을 더듬거나 옛날 블로그·깃허브를 뒤지는 시간 제거

## 아카이브 구성 원칙 (작성 규칙)
1. **팩트와 수치 중심:** 추상적인 표현 대신 문제 상황, 해결 과정, 정량적 개선 지표(성능, 지연시간, 트래픽 등)를 명확히 기록한다.
2. **원자적 분리:** 프로젝트별, 트러블슈팅별, 기술 스택별로 문서를 쪼개어 LLM이 필요한 조각만 쏙쏙 가져갈 수 있게 한다.
3. **꾸준한 현행화:** 새로운 삽질이나 성과가 생길 때마다 `git commit`으로 노역 일지를 추가한다.
