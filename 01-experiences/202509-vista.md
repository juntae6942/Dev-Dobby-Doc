# VISTA · 제주 내비게이션 프로토타입과 도로 경관 데이터

제주 도로를 대상으로 경로와 주변 위험 정보를 제공하는 내비게이션 프로토타입을 개발했다. 공동 연구에서는 로드뷰를 도로 링크별 경관 데이터로 변환해, 조망이나 경관 유형을 경로 추천에 활용할 수 있는 기반을 마련했다. [VISTA GitHub 조직](https://github.com/orgs/DigitalNomadVista/repositories)

## 직접 구현한 업무

- **제주 경로 탐색 백엔드** — Spring Boot에서 제주 OSM 데이터를 사용하는 OSRM과 연동했다. 현재 위치와 경유 좌표를 받아 경로를 조회하고, 거리·예상 소요 시간·경로 형상을 WebSocket 응답에 담는 프로토타입을 구현했다. OSRM 주소는 설정으로 분리했다. [백엔드 프로토타입](https://github.com/DigitalNomadVista/back/commit/7d6264d), [경로 엔진 설정 분리](https://github.com/DigitalNomadVista/back/commit/e3e8a99)
- **도로 위험 요소 공간 조회** — 제주 안전운전 데이터를 적재하고, 입력 좌표를 이은 `LINESTRING` 주변의 위험 지점을 PostGIS `ST_DWithin`으로 조회해 경로 응답에 포함했다. 확인한 프로토타입은 OSRM이 반환한 실제 경로 형상 대신 요청의 출발점·경유 좌표를 이어 조회하며, WebSocket 경로 생성에서 거리 기준은 100m였다. [위험 요소 조회 구현](https://github.com/DigitalNomadVista/back/commit/f9b9b03)
- **모바일 검색 프로토타입** — React Native·Expo 앱의 초기 구조를 만들고 내비게이션 API 호출 모듈과 검색 결과 컴포넌트, 음성 검색 훅과 입력 화면을 작업했다. [모바일 프로토타입](https://github.com/DigitalNomadVista/front/commit/fd743fa), [음성 입력 화면 변경](https://github.com/DigitalNomadVista/front/commit/de258fc)

## 공동 발명 · 로드뷰 기반 도로 링크 경관 속성 생성

발명신고서 초안의 공동발명자로 기재됐다. 발명 명칭은 「로드뷰 화상의 방위별 분할 취득 및 영상-언어 모델 기반 서술 종합을 이용한 도로 링크 경관 속성 자동 부여 시스템 및 방법」이다.

1. 도로망의 링크·노드 데이터에서 분석 대상 링크를 선별하고 대표 좌표를 산출한다.
2. 대표 좌표의 로드뷰에서 화면 오버레이를 제거한 뒤, 구현 예에서는 45도 간격으로 8방위 화상을 취득한다.
3. BLIP으로 방위별 기본 캡션과 경관·구조물·식생 등 관점별 서술을 생성한다.
4. DeepSeek-R1이 방위별 서술을 종합해 경관 유형, 해양·산악 조망 여부, 식생 수준, 관광 가치 등 링크 단위 속성을 JSON으로 출력한다.
5. 결과를 링크 식별자에 결합해 도로망 경관 속성 데이터로 축적한다.

발명 요약서에 따르면 실제 도로망에서 **후보 링크 9,207개 중 643개를 선별하고 642개에 경관 속성을 부여**했다. 이 수치는 팀의 데이터 처리 결과다. 경관 속성은 향후 경로 탐색 비용 함수와 도로 추천에 활용할 수 있는 입력으로 제안됐다.

## 근거와 확인 범위

- GitHub 조직의 공개 저장소 목록에서는 항목이 조회되지 않아, 조직 URL과 연결된 로컬 `back`·`front` 체크아웃에서 본인 작성 커밋과 코드를 확인했다.
- 경관 파이프라인과 처리 건수는 VISTA 로드뷰 발명신고서·발명요약서 초안에 근거한다. 연구 모듈별 개인 분담과 특허 출원·등록 상태는 해당 자료로 확인되지 않았다.
